# Supply Chain Dashboard - Excel

## Project Overview
Built an interactive Excel dashboard to analyze supply chain data including products, suppliers, revenue, and defect rates.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting

## What I Did
- Cleaned and organized 100 SKU records
- Created Summary sheet with 6 key metrics
- Built Pivot Tables for Product Type and Supplier analysis
- Created Pivot Charts for visualization

## Key Insights
1. Skincare is the top product type (₹2,41,628 revenue, 20,731 units)
2. Haircare is second (₹1,74,455 revenue, 13,611 units)
3. Cosmetics is third (₹1,61,521 revenue, 11,757 units)
4. Supplier 1 has highest revenue (₹1,57,528) but highest defect rate (48.69)
5. Supplier 4 has lowest revenue (₹86,468)
6. Total Revenue: ₹5,77,604
7. Total Products Sold: 46,099
8. Average Price: ₹49.24
9. Average Defect Rate: 2.27
10. Total Costs: ₹52,924
